# ESN-anomaly-detection-

![License](https://img.shields.io/badge/License-All%20Rights%20Reserved-red)

**Author:** Mann Patel

This repository presents an innovative approach to anomaly detection in industrial machinery using Echo State Networks (ESN). Unlike traditional methods, ESNs offer a time-efficient training process, making them particularly suitable for real-time applications involving temporal data.

## Key Features

- **Echo State Network Implementation**: Utilizes ESN to model complex temporal dynamics inherent in industrial systems.
- **Anomaly Detection**: Identifies deviations from normal operational patterns, enabling early fault detection.
- **Efficient Training**: ESN's architecture reduces training time compared to conventional neural networks.
- **Real-Time Application**: Designed for scenarios requiring immediate anomaly detection without extensive computational resources.

## Repository Contents

- `Code.py`: Core implementation of the ESN model for anomaly detection.
- `ESN2.ipynb`: Jupyter notebook demonstrating the application of ESN on sample datasets.
- `continuous_factory_process.csv`: Sample dataset representing continuous industrial processes.
- `CMAPSSData.zip`: NASA's C-MAPSS dataset for engine degradation simulation.
- `Licence`: Contains the proprietary license details restricting the use and distribution of the code.
